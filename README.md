# literarymarketing

Website for literarymarketing: book marketing for authors, novelists and publishers.
Live reference: https://literarymarketing.lovable.app

## Run
```bash
npm install
cp .env.example .env.local   # fill in values
npm run dev
```

Build: `npm run build`. Edit all business content in `src/content/site.ts`. Plan and status: `docs/ROADMAP.md`.
